# Tile Marker

A RuneScape plugin for marking ground tiles with persistent colours, labels,
and presets.

## Use

- Open Tile Marker from the PrettyUI ribbon.
- Hold **Ctrl+Shift** and right-click a visible tile to mark, unmark, or customize it.
- Manage marker styles and shareable presets from the plugin window.
- Right-click the world map button for bulk actions on visible markers.
